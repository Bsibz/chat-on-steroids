## 2.1.17 Exact fresh-chat destination routing

- Night Build New Chat restores the exact recorded source conversation when necessary, then derives the destination directly from that provider URL.
- Project sources open exactly that Project's fresh-home route; ordinary sources open a root fresh chat. Unrecognized routes fail closed.
- Destination creation is reserved before the browser side effect, preventing duplicate fresh chats after ambiguous browser failures.

The existing stable unpacked companion folder remains valid; no new Load unpacked setup is required.
