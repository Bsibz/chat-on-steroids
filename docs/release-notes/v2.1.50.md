## 2.1.50 Native attachment Send readiness diagnostics

- When a claimed Native Chat attachment send remains stalled before native Send authorization, CoS now records a bounded readiness breadcrumb with only attachment/control counts and composer/generation booleans.
- No prompt text, filenames, attachment bytes or page prose are recorded, and this release does not loosen any Send, ownership, model-selection, upload-timeout or native-receipt gate.
