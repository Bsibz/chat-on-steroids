## 2.1.53 Native Chat exact-tab identity after Settings

- Stable ChatGPT Settings and other non-conversation routes no longer masquerade as remembered copies of a conversation.
- This fixes pinned Night Build Native Chat sends that timed out before browser claim when Plugins Settings tabs retained an older conversation registry identity.
- Transient root/no-URL reload recovery remains supported, and Native Chat still requires exactly one current owned conversation document before offering a send.
