## 2.1.47 Native Chat in-process metadata reuse

- Repeated Native Chat list, control, owner-control and handle-resolution reads now reuse CoS's process-lifetime session metadata index instead of reopening every retained session metadata file on each Night Build poll.
- Transcript projection still rereads the selected session's durable metadata and keeps the existing before/after/final projection-change fences, so the optimization does not turn cached metadata into transcript truth.
- Compact & Resume, stale handles, duplicate conversation ownership and mutation authority remain fail-closed, and the standalone read-only sidecar keeps its independent file-backed catalog path.
