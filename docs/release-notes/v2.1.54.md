## 2.1.54 Native Chat concrete document custody

- Native Chat authored sends now require one concrete current ChatGPT conversation document before the browser can receive the intent. Registry memory, transient roots, Settings pages, and helper navigation cannot authorize a send.
- Project-chat, reload, plugin-helper, duplicate-document, one/two-PNG, stale-row, and arbitrary-file routing regressions are covered.
- Busy ChatGPT pages still fail closed: this release does not force a send through a visible Stop state, and it does not yet expose generic video/file staging in the Night Build composer.
