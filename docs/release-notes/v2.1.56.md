## 2.1.56 Release auto-compaction after terminal Native Chat ACK

- Native Chat mutation custody now ends when an authorized browser send has durably reached terminal `sent` state, even if recorder-level acceptance metadata is projected later.
- This fixes automatic compaction retrying forever with `native_chat_mutation_pending` after a successfully delivered Native Chat send.
- Authorized unknown outcomes and unsettled Stop ownership remain fail-closed.
