## 2.1.46 Current ChatGPT attachment input compatibility

- ChatGPT's current composer uses generated file-input ids rather than the historical `upload-photos` / `upload-files` ids.
- CoS now binds image sends to the unique exact `image/*` input and arbitrary-file sends to the unique unrestricted input inside the active composer.
- The broader image/video picker is never mistaken for the still-image input, and ambiguous exact matches fail closed.
- Existing attachment ownership remains strict: every requested file still needs its own newly observed exact tile and upload-complete state before Send can proceed.
