## 2.1.19 Daily-driver performance and recovery

- Explicit absolute Core reads can stay request-scoped under Allow unattributed calls instead of paying historical worker identity waits; mutating, workspace-dependent and positively identified worker calls keep their existing fail-closed gates.
- Request attribution now shares one ingress-started evidence budget, suppresses repeated unresolved diagnostics, and avoids worker-owner reconciliation when there is nothing to reconcile.
- Worker bootstrap tolerates delayed ChatGPT composer mounts with bounded backoff while enforcing the app-owned absolute command expiry before Send.
- A successful owner connection is restored on ordinary relaunch with finite backoff; explicit Disconnect persists and cancels reconnect.
- Packaged builds refresh `~/Library/Application Support/chat-on-steroids/extension` on startup. Local/unpublished builds use that stable folder instead of inventing GitHub assets.
- `Resume stream unavailable` is recorded as a recoverable ChatGPT transport failure and uses the existing one-shot, turn-scoped recovery path without re-sending the user's turn.

Reload the existing unpacked Chat On Steroids companion after updating. No Load unpacked step is required.
