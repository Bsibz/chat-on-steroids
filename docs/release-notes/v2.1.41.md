## 2.1.41 Leaner tool context and idle tabs

- Completed-session polls omit command text that an earlier tool result already delivered, so CoS stops spending context on output it has already seen. This replay suppression is the main context saving; `reread_retained=true` remains available for an intentional exact reread without rerunning the command.
- Command output keeps both MCP representations required by ordinary clients and ChatGPT Code Mode. CoS records one authored copy instead of serializing the mirrored `structuredContent.output` body as a duplicate local copy; that removes a redundant duplicate, not the primary context saving.
- Context meters describe their source accurately as local recorded-text estimates rather than implying provider context-window occupancy.
- Hidden idle ChatGPT tabs back the full CoS DOM reconciliation loop off from one second to ten seconds while retaining immediate mutation handling and eager foreground catch-up.
- Automatic connector refresh no longer shows the contradictory manual refresh reminder when the feature is enabled.
- A stuck macOS Keychain availability probe can no longer hold the whole UI at startup. Secure-storage reads now time out fail-closed, expose no credentials, and can be retried by later state refreshes.

The verified local updater owns installation and Chrome companion self-refresh. Changed connector schemas use the existing bounded ChatGPT Settings helper refresh path when Automatic plugin refresh is enabled.
