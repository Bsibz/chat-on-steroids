## 2.1.23 ChatGPT search-unit renderer

- Native Chat follows ChatGPT's current search-unit renderer when legacy conversation-turn and message attributes are absent.
- User and assistant message ids, roles and authored text are recovered from provider-owned search-unit anchors while canonical transcript identity remains page-model backed.
- The new authored units receive the same bounded DOM-to-Fiber turn stamp used by lifecycle, Stop and attribution.
- Structural page-model diagnostics now survive filtering, making future renderer drift directly diagnosable.
- An invalid explicitly configured tunnel binary path now fails closed instead of falling back to another binary.
