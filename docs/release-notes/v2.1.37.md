## 2.1.37 Controller-driven local updater

- Add a bounded packaged-macOS `--install-local-update` command so an owner-authorized local controller can trigger the verified updater without manually replacing the app.
- The command does not choose an app, archive, version, path, or hash. It only asks the already-running primary to check its fixed local channel and proceed when the existing updater has verified a candidate.
- Startup and second-instance requests are deferred until normal app initialization is complete, then use the same bounded shutdown, post-quit verification, rollback, and relaunch path as the in-app Install button.
- Development runs and non-macOS platforms reject this command; public macOS releases remain on the existing manual path.

Reload the matching unpacked companion after updating.
