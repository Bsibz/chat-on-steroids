## 2.1.44 Night Build owner controls and daily-driver hardening

- CoS now publishes a separate authenticated `night-build-chat-owner-control-v1` loopback lane for one exact Night Build Native Chat conversation.
- Night Build can read configured versus effective automatic compaction, Off/Goal/Loop mode, and durable Compact & Resume state, then request only the mutations CoS already owns.
- Exact conversation handles are revalidated around awaited work; stale, changed, superseded, busy, worker and blocked states fail closed instead of retargeting another chat.
- Manual compaction exposes the real cancel boundary: once commit is landing, Night Build sees that it is already committing rather than claiming cancellation succeeded.
- The frozen Native Chat v3 contract remains byte-untouched and owner-control startup is additive, so a v1 lane failure cannot take down existing Native Chat read/write transport.
- Local recorded-token triggers stay explicitly local estimates and are never presented as ChatGPT provider context occupancy.

The verified local updater owns installation and companion refresh.
