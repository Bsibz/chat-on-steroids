## 2.1.21 Worker tab placement

- Worker chats now stay with the browser profile that owns their prime chat when that ownership is known.
- Unattributed worker openings are pinned to one live browser profile for a renewable lease, preventing concurrent workers from racing into separate Chrome windows/profiles.
- The extension publishes a session-scoped, non-secret browser placement identity solely for coordinating fresh worker tabs.
