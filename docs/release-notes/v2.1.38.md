## 2.1.38 One-step app + companion update

- The old companion reloads only when the packaged app proves its stable companion matches the new app and that exact extension id independently sees the same new manifest in its own authorized root.
- A durable from-version fence plus a pre-await single-flight prevents a broken reload, rotating peer versions, or overlapping hellos from looping.
- Existing ChatGPT tabs are repaired in place through one startup recovery flight with the current DOM, Fiber, usage, and content helpers; healthy tabs are not navigated or refreshed.
- Fiber recovery now verifies helper version 16 and removes stale MAIN-world listeners from older helper versions.
- The existing manual reload warning remains the fallback if Chrome cannot complete the automatic reload.
