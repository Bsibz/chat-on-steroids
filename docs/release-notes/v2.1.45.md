## 2.1.45 Compaction Stop fallback

- Manual and automatic Compact & Resume still file one durable ticket before touching the page.
- CoS asks ChatGPT to stop the active turn once. If the current ChatGPT shell ignores that Stop, the ticket is no longer treated as a failed compaction.
- The same exact ticket waits for the source turn to become idle, then resumes through the existing tool-settle, marked handoff, fresh-chat and continuation path.
- Repeated activity polls do not repeatedly hammer Stop while the same source turn is still generating.
- Explicit Cancel still retires the durable transaction immediately, and all existing exact-conversation/send checkpoint fences remain in force.
