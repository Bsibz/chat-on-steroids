## 2.1.36 Owner-local macOS update channel

- Add a fixed local macOS development channel so future dogfood builds can be staged and installed from Chat On Steroids instead of manually replacing the app bundle.
- Each candidate is bound to its exact version, architecture, product identity, versioned ZIP name, and SHA-256; the app rehashes it before staging and again at install handoff.
- Local macOS installation is owner-explicit only. The post-quit helper validates the extracted bundle seal, identity, version, and architecture, restores the previous app on a failed swap, and relaunches the same installed path.
- `npm run local:update:mac` now performs the full source verification, packages this Mac's architecture, smoke-tests the runtime/bundle/GUI and extracted ZIP, then publishes the local candidate without modifying the installed app.
- Public macOS releases remain manual because the current artifacts are ad-hoc sealed and unnotarized.

Reload the matching unpacked companion after updating.
