## 2.1.42 Modern composer recovery and context truth

- CoS recognizes ChatGPT's current scoped composer when the old `#prompt-textarea` node is absent. The same composer primitive now serves fresh worker bootstrap and Compact & Resume, repairing the local paths that had been reloading or refusing while ChatGPT's newer editor was already mounted.
- Automatic compaction remains an explicitly enabled local recorded-text heuristic. CoS does not claim to know ChatGPT provider context occupancy, hidden reasoning, system prompts, tool schemas or provider-side compaction.
- Completed-session polls omit command output that an earlier result already delivered. `reread_retained=true` performs the deliberate exact reread and never reruns the command.
- Model-visible instructions, retained-output diagnostics, the context meter and localized labels now describe those semantics consistently.
- Ordinary MCP clients and ChatGPT Code Mode keep their required result representations; CoS records one authored local output copy rather than counting a mirrored protocol body twice.

The verified local updater owns installation and companion refresh.
